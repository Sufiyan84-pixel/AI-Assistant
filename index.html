How It Works
From voice to action




1
Wake
User says the wake word and ESP-SR detects it.


2
Listen
The I2S mic records the voice command.


3
Send
Audio goes to cloud STT, with MQTT carrying the messages.


4
Think
The LLM processes the text and generates a reply.


5
Speak
TTS audio plays through the MAX98357.


6
Act
Commands trigger the relay and lights.

Getting Started
4 steps to go live




1
Flash the Firmware
Open Arduino IDE, select the ESP32-S3 board and upload main.cpp. Install the ESP-SR and LVGL libraries first.


2
Configure WiFi + MQTT
Edit config.h with your WiFi credentials and MQTT broker URL, then re-upload the firmware.


3
Set Up Cloud AI
Deploy STT, LLM and TTS endpoints (or your own server) and add the API keys to config.h.


4
Wire the Hardware
Connect mic, amp, OLED and buttons as in the wiring diagram. Power on and test.

FAQ
Quick answers




What is the ESP32-S3 AI Voice Assistant?
A voice-controlled smart assistant on the ESP32-S3 with wake word detection, an LVGL display, WiFi/MQTT and cloud AI.


Does it work offline?
Wake word detection and the display run on the device. Speech-to-text, the LLM and text-to-speech need a network connection to your AI server.


Which wake word engine is used?
ESP-SR, Espressif's on-device speech recognition framework.


Can I use my own AI server?
Yes. Point STT_ENDPOINT, LLM_ENDPOINT and TTS_ENDPOINT in config.h to your own services.


How much RAM does it need?
The reference build uses an ESP32-S3 with 8MB PSRAM and 16MB Flash, which gives room for audio buffers, LVGL and the models.


Can I add custom skills/tools?
Yes. The built-in MCP server exposes tools such as lamp, volume and screen control, and you can register more.
